# 학생 평가 결과 분석기

학생 답안 시트를 올리면 자동으로 채점하고, 성취수준 분포·문항별 정답률·학생별 성적을 보여주는 단일 HTML 파일 웹앱입니다.

`index.html` 하나만 있으면 됩니다. 설치도 서버도 필요 없고, 파일을 더블클릭하면 브라우저에서 바로 열립니다.

## 쓰는 순서

1. **문항 설정** — 답안 시트를 올리면 문항 수와 학생 답안이 한 번에 채워집니다. 파일 없이 문항 수만 정해도 됩니다.
2. **정답 입력** — 표에 직접 입력하거나 정답지 파일을 올립니다.
3. **학생 답안 입력** — 표에 직접 입력하거나 답안 파일을 올립니다.
4. **분석 결과** — 통계, 성취수준 분포, 문항별 정답률, 오답 TOP 5, 학생별 성적과 정오답 히트맵.

## 어떤 시트를 읽나요

머리글 행에 `이름`이 있고 그 옆에 문항 번호 열이 있으면 됩니다. 열 순서가 달라도 찾아서 씁니다.

| 번호 | 이름 | 1 | 2 | 3 | 제출시각 |
|---|---|---|---|---|---|
| 1 | 홍길동 | 4 | 5 | 사과 | 2026-08-19 11:38 |
| 2 | 김서연 | 3 | 5 | 사과 | 2026-08-19 11:41 |
|  | 정답 | 4 | 5 | 사과 |  |
|  | 배점 | 30 | 30 | 40 |  |

- `제출시각` 같은 열은 자동으로 건너뜁니다. 구글 폼 응답 시트를 그대로 올려도 됩니다.
- 이름 칸이 `정답`·`배점`·`유형`인 행은 학생이 아니라 정답·배점·문항 유형으로 읽습니다.
- `설정` 시트에 `평가명`, `문항수`가 있으면 함께 읽어옵니다.
- 시트가 여러 개면 학생 답안 시트를 알아서 고릅니다.
- 엑셀(.xlsx)과 CSV를 지원합니다. 구글 시트는 링크를 붙여넣으면 내려받기 링크를 만들어 줍니다.

## 채점 규칙

정답이 여러 개 인정되면 `/`로 구분합니다 (예: `사과/apple`).

표기가 조금 달라도 같은 답으로 인정합니다.

- `①②③` · `❶` · `㉠` 같은 동그라미 기호 → `1`, `2`, `3`, `ㄱ`
- 전각 숫자 → 반각 숫자
- 띄어쓰기 차이 (`대한 민국` = `대한민국`)
- 영문 대소문자 (`APPLE` = `apple`)
- 끝에 붙은 마침표·쉼표

## 저장

채점 결과와 리포트는 파일로 저장하거나, `표 복사`로 엑셀·구글 시트에 바로 붙여넣을 수 있습니다. 결과 인쇄에서 `PDF로 저장`을 고르면 컬러 리포트가 나옵니다.

## 알아두실 점

- 입력한 내용은 **그 브라우저에만** 저장됩니다. 서버로 보내지 않습니다.
- 다른 기기에서 이어서 하려면 결과를 파일로 저장해 옮겨주세요.
- 다른 반이나 다른 시험을 채점하려면 오른쪽 위 `새 평가 시작`을 누르세요.
- 외부 라이브러리를 쓰지 않습니다. 엑셀 읽기·쓰기도 브라우저 기본 기능만으로 처리합니다.
